DoorJam

An Owlbear Rodeo enhancement that turns ordinary door artwork into synchronized controls for Dynamic Fog and Smoke & Spectre!

Quick Start

Source and installation

  1. Drag an image representing a closed door over a Dynamic Fog or Smoke & Spectre! door.
  2. Us the DoorJam tools, or right-click context menu, to link the door item to the nearest Dynamic Fog or Smoke & Spectre! door.
  3. Assign an image to represent the open state. Your DoorJam door is now linked to the fog or smoke door. You can operate the door from either the DoorJam tools or the linked door item.

Of course, you can use DoorJam without linking it to a fog or smoke door to create a simple, visual door open/close effect. In this case, you're simply switching between two images, so you're not necessarily limited to "doors".

Tool Modes

DoorJam Tools (J)

Opens the DoorJam tool panel.

Operate Door (O)

Clicking an established DoorJam door item with this tool will toggle its open/closed state. If the door is linked to a Dynamic Fog or Smoke & Spectre! door, that door will open or close accordingly.

Lock/Unlock Door (L)

Clicking an established DoorJam door item with this tool will toggle its locked/unlocked state. Locked doors are not operable by players (even if player door operation is otherwise allowed). However, doors are always operable by a GM.

Set Image (I)

Clicking an item with this tool will allow you to set the images for the open and closed state. Once both images are set, the item becomes an operable DoorJam door.

Link/Create Dynamic Fog Door (Y)

Clicking an item with this tool will attempt to link it to an existing Dynamic Fog door, or create a new Dynamic Fog door where the image intersects with a fog boundary. This enables synchronized operation between the door and the fog effect.

Link/Create Smoke & Spectre! Door (K)

Clicking an item with this tool will attempt to link it to an existing Smoke & Spectre! door, or create a new Smoke & Spectre! door where the image intersects with a straight, unbroken Obstruction Line. This enables synchronized operation between the door and the obstruction line.

Break Link (B)

Clicking an item with this tool will allow you to break the link between it and any associated Dynamic Fog or Smoke & Spectre! door. The item will still behave as a standard, DoorJam door, and can be linked to another door as desired.

Remove Door (R)

Clicking an item with this tool will change it from a DoorJam door to a standard object. If the item is currently linked to a Dynamic Fog or Smoke & Spectre! door, the link will be broken but the underlying door will remain.

Allow/Prevent Player Door Operation (X)

Clicking this tool enables or disables player operation of all DoorJam doors in the scene. Individual door operation can be overridden with the Lock/Unlock Door tool.
